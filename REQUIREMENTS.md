# Requirements
*written retroactively on 2026-08-16, from README.md and the tree; revised 2026-09-06 for the two-audience split.*

## North Star
A stranger can install a skill or plugin from a joey.ai post and get a working artefact, not a description of one.

## V1
*What has shipped.*
- `skills/profile-builder` — [Start with your profile](https://joeyai.substack.com/p/the-profile)
- `skills/coworker` — [Stop starting every session cold](https://joeyai.substack.com/p/the-coworker-layer)
- `plugins/vibe` — marketplace install via `/plugin marketplace add the-joey-ai/joey-ai`
- `plugins/constitutional-pattern` and `plugins/my-method` — the same marketplace, two audiences

## Non-Goals
- Being the owner's working method. That lives in private and arrives here as cleaned copies.
- Bidirectional sync with any private project.
- Teaching facts, paths, or data that only matter to the owner.
- Completing a document set. This project earns a thin publishing set.
