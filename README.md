# claude-skills

Claude skills that ship with the [joey.ai](https://joeyai.substack.com) Substack — the Constitutional Pattern layer series.

Each folder holds one skill: its `SKILL.md` (readable inline, for transparency) plus the packaged `.skill` file you can download and drop into Claude.

## Skills

- **`profile-builder/`** — builds or refines your Claude profile (work, personal, or whole-self) through a guided, philosophy-driven conversation. Ships with the post *Start with your profile*.

## Using a skill

Download the `.skill` file from its folder and add it to Claude. The matching `SKILL.md` is there if you'd rather read what it does first.
